# threads-poster

스레드(Threads)에 글을 자동으로 올려주는 저장소예요. 컴퓨터를 꺼놔도 GitHub가 정해진 시간에 한 편씩 올려요.

## 어떻게 돌아가나요

1. `queue` 폴더 안에 **글 하나당 폴더 하나**를 만들어요. 예: `001-iljichuk`
2. 폴더 안에 아래 파일을 넣어요.
   - `text.txt` : 본문 (500자까지)
   - 이미지 `1.png`, `2.png` … : 이름 순서대로 올라가요. 1장이면 한 장, 2장 이상이면 넘겨보는 형식이에요. (png/jpg, 한 장에 8MB 이하, 최대 20장)
   - `READY.txt` : **"이 글 올려도 좋아요"** 표시. 이 파일이 없으면 절대 올라가지 않아요.
3. 정해진 시간이 되면 `READY.txt`가 있는 폴더 중 **이름이 가장 앞선 글 1개**가 올라가요.
4. 올라간 글은 `posted` 폴더로 옮겨져요. 올라간 글 주소는 그 폴더의 `result.json`에 남아요.

> `queue` 폴더는 인터넷에 공개돼 있어요. 아직 올리지 않은 만화와 글도 주소를 아는 사람은 볼 수 있어요.

## 글 추가하는 법

1. 저장소 첫 화면에서 `queue` 폴더로 들어가요.
2. **Add file → Upload files**로 폴더째 끌어다 놓거나, **Create new file**에서 `001-iljichuk/text.txt`처럼 경로를 적어 만들어요.
3. 폴더 이름은 **영어와 숫자**로 지어주세요. 순서대로 올라가니 `001-`, `002-` 처럼 번호를 앞에 붙여요.
4. 올릴 준비가 끝나면 그 폴더 안에 **Create new file**로 `READY.txt`를 만들어요. 내용은 아무거나 괜찮아요. (예: `ok`)

## 처음 한 번만 하는 설정

저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 아래를 만들어요.

| 이름 | 내용 | 꼭 필요? |
|---|---|---|
| `THREADS_ACCESS_TOKEN` | 스레드 접근 토큰 | 필수 |
| `GH_PAT` | 토큰 자동 갱신용 GitHub 토큰 | 선택 |
| `THREADS_APP_SECRET` | Threads 앱 시크릿 | 선택 |

토큰은 비밀번호예요. 파일이나 글에 절대 적지 마세요. 위 Secrets에만 넣어요.

## 잘 되는지 확인하는 순서

1. 저장소 **Actions** 탭 → **연결 확인** → **Run workflow**. `연결 성공: @계정이름`이 나오면 토큰이 맞아요.
2. **Actions** → **스레드 자동 발행** → **Run workflow** (`dry_run`은 `true` 그대로). 실제로 올리지 않고 어떤 글이 올라갈지만 보여줘요.
3. 마지막으로 `dry_run`을 `false`로 바꿔 실행하면 진짜로 한 편이 올라가요.

## 발행 시간 바꾸기

`.github/workflows/post.yml`의 `cron:` 줄을 고쳐요. 시간은 **한국 시간에서 9시간을 뺀 값(UTC)**이에요. `cron` 줄 하나가 하루에 한 번이고, 한 번 실행할 때 글 1개가 올라가요. 하루에 여러 번 올리려면 줄을 여러 개 두세요.

지금 설정은 하루 3번이에요.

| 한국 시간 | cron |
|---|---|
| 오전 8시 30분 | `30 23 * * *` |
| 낮 12시 30분 | `30 3 * * *` |
| 저녁 6시 30분 | `30 9 * * *` |

다른 예시:

| 원하는 시간 (한국) | cron |
|---|---|
| 매일 오후 8시 | `0 11 * * *` |
| 월·수·금 오후 8시 | `0 11 * * 1,3,5` |

GitHub 사정으로 몇 분에서 길게는 수십 분 늦게 올라갈 수 있어요.

## 토큰 자동 갱신 (선택)

스레드 토큰은 60일이 지나면 만료돼요. `토큰 갱신` 워크플로가 매달 1일에 새 토큰으로 바꿔 Secrets에 다시 저장해요. 이를 쓰려면 `GH_PAT` 시크릿(이 저장소의 Secrets를 수정할 수 있는 GitHub 토큰)이 필요해요. `GH_PAT`가 없으면 이 워크플로는 아무것도 하지 않고 넘어가요. 그 경우 60일마다 `THREADS_ACCESS_TOKEN`을 직접 새로 만들어 넣어야 해요.

## 폴더 구성

```
queue/           올릴 글 (글 하나당 폴더 하나)
posted/          이미 올린 글
scripts/         발행 프로그램 (threads_tool.py)
.github/workflows/   자동 실행 설정 (발행, 연결 확인, 토큰 갱신)
```
